# Runbooks

Start here when something is wrong with a Crux release or a running server.

| Symptom | Runbook |
| --- | --- |
| `crux serve` is down, `/v1/health` fails, the hive callback is unreachable, or an agent is stuck | [agent-not-working.md](agent-not-working.md) |
| A published release is broken and must be withdrawn or superseded | [release-rollback.md](release-rollback.md) |
| After any incident that reached users | [postmortem-template.md](postmortem-template.md) |
